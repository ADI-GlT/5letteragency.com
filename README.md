# 5 Letter Agency

Public website for 5 Letter Agency's Google Business Profile and reputation-management service.

Live site: https://5letteragency.com/

## Local preview

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`.

## Runtime

Static HTML, CSS, and JavaScript. No build step or server-side runtime.
